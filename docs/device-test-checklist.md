# 実機テスト項目（保存・読み込み）

対象: iOS Safari（iPhone / iPad）、Android Chrome。
試験公開 URL（ログイン必須）: https://web-madori-trial.vercel.app/editor/

各項目に「端末・OS・ブラウザのバージョン」「結果（○ / × / △）」「× の場合は画面の写真と手順」を記録する。

## 1. まとめて保存（保存ボタン）

| # | 確認内容 | 期待結果 | iOS Safari | Android Chrome |
| --- | --- | --- | --- | --- |
| 1-1 | 上部の「保存」を押す | 保存・出力画面が開き、5 形式すべてにチェックが入っている | | |
| 1-2 | 「保存される範囲」を読む | 編集用データ＝すべての案、間取り図・PDF＝編集中の案のみ、と分かる | | |
| 1-3 | 画面を最後までスクロール | 右端のバーが動き、最後の項目まで見える。保存ボタンは常に画面下に見える | | |
| 1-4 | プレビューの 基本 / 寸法付き / 家具付き を切り替える | それぞれ表示される | | |
| 1-5 | そのまま「まとめて保存する（ZIP）」 | iOS: 「ダウンロードしますか？」→ ダウンロード。Android: ダウンロード通知が出る | | |
| 1-6 | 保存先のファイル名を確認 | `プロジェクト名.zip`（日本語名のまま。`download` にならない） | | |
| 1-7 | ZIP を開く（iOS:「ファイル」アプリでタップして展開 / Android:「Files」アプリで展開） | `project.floorplan` / `floorplan.png` / `floorplan_dimensions.png` / `floorplan_furniture.png` / `floorplan.pdf` の 5 つ | | |
| 1-8 | 3 つの PNG を開く | 間取りの形・位置が同じ。寸法付きは寸法線つき、家具付きは家具つき。文字が重なっていない | | |
| 1-9 | PDF を開く | 3 ページ（基本・寸法付き・家具付き）。A4 で崩れていない | | |
| 1-10 | 「家具配置付き間取り図」だけ ON にして保存 | ZIP ではなく `プロジェクト名_B案_家具.png` 単体で保存される（案の名前が付く） | | |
| 1-11 | 「編集用データ」だけ ON にして保存 | `プロジェクト名.floorplan` 単体（`.floorplan.json` などにならない） | | |

| 1-13 | 「ダウンロードしますか？」の確認で 10 秒以上待ってから「ダウンロード」を押す（iOS） | 正常に保存される（以前は待つと失敗する可能性があった） | | — |
| 1-14 | 保存した PNG を写真アプリに保存（iOS: ファイル → 共有 → 画像を保存 / Android: ギャラリーで表示） | 写真として保存・表示できる | | |
